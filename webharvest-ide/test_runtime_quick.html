Quick Runtime Test - Connection Rendering Fixes

Test 1: Sprawdzenie czy IDE działa

Otwórz http://localhost:8080

Przełącz na tryb wizualny i dodaj kilka węzłów

Test 2: Sprawdzenie konsoli przeglądarki

Otwórz DevTools (F12) i sprawdź konsolę:

  • ✅ Powinny być logi: "Registered anchor: ..."
  • ✅ Powinny być logi: "Registered SVG element"
  • ✅ Powinny być logi: "Recalculated connection ..."
  • ⚠️ Nie powinno być: "Connection ... marked as pending" (lub tylko na początku)

Test 3: Debug Overlay

W konsoli przeglądarki wykonaj:

window.__DEBUG_CONNECTIONS__ = true;

Następnie odśwież stronę (F5)

Powinny pojawić się:

  • Niebieskie kropki - pozycje z modelu
  • Czerwone kropki - pozycje z DOM
  • Pomarańczowe linie - różnice > 2px

Test 4: Sprawdzenie czy linie są w prawidłowych miejscach

Wizualnie sprawdź czy:

  • Linie łączą się ze środkowymi punktami węzłów (center points)
  • Linie nie są w "losowych miejscach"
  • Linie są ortogonalne (tylko poziome i pionowe segmenty)

Test 5: Sprawdzenie podczas drag

Przeciągnij węzeł i sprawdź:

  • Czy linie aktualizują się płynnie (RAF batching)
  • Czy nie ma błędów w konsoli
  • Czy linie pozostają w prawidłowych pozycjach
