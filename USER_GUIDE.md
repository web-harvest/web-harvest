## Before following an installation or IDE guide

The Maven version declared in `pom.xml` is project metadata; it does not establish that a matching IDE JAR, installer or Maven artifact has been published. Use installation instructions only when they are tied to a verified release artifact and its exact version.

The project is revalidating the IDE's current user-facing workflows before publishing a replacement manual. Until that work is complete, do not rely on the archived guide's JAR names, port settings, API endpoint behavior, keyboard shortcuts, session/token metrics or Visual Designer feature list.

## Documentation language

Current project-facing documentation is written in English. Historical material may be retained in its original form for traceability, but it must be clearly labeled as historical and must not be presented as current product guidance.
