# WebHarvest Design System v2.2 - Professional Enterprise Level

## 🎯 Principles

1. **Professional First** - Enterprise tool, not consumer app
2. **Consistent** - Website + IDE share same components
3. **Modern** - 2025 design trends, not 2010
4. **Accessible** - WCAG AAA compliance
5. **Performant** - Fast loading, smooth animations

## 🎴 Components

### Cards
- **Base:** White background, 1px border, subtle shadow
- **Hover:** Lift 4px, stronger shadow, accent border
- **Radius:** 16px (large), 12px (medium), 8px (small)

### Buttons
- **Primary:** Gradient purple→pink, white text, bold shadow
- **Secondary:** Outline with gradient on hover
- **Ghost:** Transparent, accent text

### Icons
- **Size:** 24px standard, 32px large, 48px hero
- **Style:** Duotone from Font Awesome Pro or custom SVG
- **Color:** Match gradient or solid accent

---

## 🏗️ Layout Patterns

### Hero Section
```
2-column grid (60/40 split)
Left: Headline + Description + CTA buttons
Right: Hero visual (illustration/screenshot)
Background: Gradient with subtle pattern
Padding: 6rem vertical
```

### Feature Cards
```
3-column grid on desktop
Icon (gradient background) + Title + Description + Links
Shadow on hover, border accent
Clean, spacious (3rem gap)
```

### Processor Grid
```
4-5 columns auto-fill (min 160px)
Icon + Name + Short description
Grouped by category
Click → full documentation
```
