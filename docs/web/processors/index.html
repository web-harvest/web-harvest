Web & HTTP Processors

<http>

View Details

Performs HTTP requests to fetch web content

Key Attributes:

  • url - Target URL (required)
  • method - HTTP method
  • timeout - Request timeout

Example:

http-example.xml 
<http url="https://example.com" method="GET" timeout="30000">
    <http-header name="Accept">application/json</http-header>
    <http-param name="page">1</http-param>
</http>

<html-to-xml>

View Details

Converts HTML content to well-formed XML using advanced parsing strategies

Key Features:

  • advancedxmlescape - XML character escaping
  • unicodechars - Unicode support
  • omitunknowntags - Clean unknown tags

Example:

html-to-xml-example.xml 
<html-to-xml 
    advancedxmlescape="true" 
    specialentities="true" 
    unicodechars="true">
    <http url="https://example.com"/>
</html-to-xml>

<web-browser>

View Details

Headless web browser for JavaScript-heavy sites using PhantomJS

Key Attributes:

  • path - PhantomJS executable path
  • port - Communication port

Example:

web-browser-example.xml 
<web-browser path="/usr/bin/phantomjs" port="8081">
    <web-browser-load url="https://spa.example.com"/>
    <web-browser-javascript>
        return document.querySelector('.content').innerHTML;
    </web-browser-javascript>
</web-browser>

Data Extraction Processors

<xpath>

View Details

Extracts data using XPath expressions

Key Attributes:

  • expression - XPath expression

Example:

xpath-example.xml 
<xpath expression="//div[@class='product']//h3">
    <html-to-xml>
        <http url="https://shop.example.com"/>
    </html-to-xml>
</xpath>

<xquery>

View Details

Advanced data processing using XQuery 3.1

Example:

xquery-example.xml 
<xquery>
    <xq-param name="data">
        <get var="xmlData"/>
    </xq-param>
    <xq-expression>
        <![CDATA[
        declare variable $data as node() external;
        <results>
            {
                for $item in $data//item
                return <item>
                    <name>{$item/name}</name>
                    <price>{$item/price}</price>
                </item>
            }
        </results>
        ]]>
    </xq-expression>
</xquery>

<regexp>

View Details

Pattern matching and text extraction using regular expressions

Key Attributes:

  • pattern - Regex pattern
  • action - Action type

Example:

regexp-example.xml 
<regexp pattern="<title>(.*?)</title>" action="match">
    <http url="https://example.com"/>
</regexp>

File & Data Processors

<file>

View Details

File read/write operations

Key Attributes:

  • path - File path
  • action - Action type

Example:

file-example.xml 
<file path="output.xml" action="write" charset="UTF-8">
    <template>
        <![CDATA[
        <results>
            <title>${title}</title>
            <content>${content}</content>
        </results>
        ]]>
    </template>
</file>

<json-to-xml>

View Details

Converts JSON data to XML format

Example:

json-to-xml-example.xml 
<json-to-xml>
    <http url="https://api.example.com/data"/>
</json-to-xml>

<xml-to-json>

View Details

Converts XML data to JSON format

Example:

xml-to-json-example.xml 
<xml-to-json>
    <get var="xmlData"/>
</xml-to-json>

Control Flow Processors

<loop>

View Details

Iterates over a collection of items

Key Attributes:

  • item - Current item variable
  • maxloops - Max iterations

Example:

loop-example.xml 
<loop item="product" index="i" maxloops="10">
    <list>
        <constant>Product 1</constant>
        <constant>Product 2</constant>
    </list>
    <body>
        <def var="productName">
            <get var="product"/>
        </def>
    </body>
</loop>

<while>

View Details

Repeats execution while condition is true

Key Attributes:

  • condition - Condition expression

Example:

while-example.xml 
<while condition="${pageUrl.toString().length() != 0}" maxloops="10">
    <def var="content">
        <http url="${pageUrl}"/>
    </def>
    <def var="nextPage">
        <xpath expression="//a[@class='next']/@href">
            <get var="content"/>
        </xpath>
    </def>
    <def var="pageUrl">
        <get var="nextPage"/>
    </def>
</while>

<if>

View Details

Conditional execution based on expression

Example:

if-example.xml 
<if condition="${price < 100}">
    <then>
        <def var="alert">Price is below threshold!</def>
    </then>
    <else>
        <def var="alert">Price is above threshold.</def>
    </else>
</if>

Variable Processors

<def var>

View Details

Defines a new variable with a value

Example:

def-var-example.xml 
<def var="productUrl">https://shop.example.com/product/123</def>
<def var="productData">
    <html-to-xml>
        <http url="${productUrl}"/>
    </html-to-xml>
</def>

<get var>

View Details

Retrieves the value of a variable

Example:

get-var-example.xml 
<def var="title">
    <xpath expression="//title">
        <get var="pageContent"/>
    </xpath>
</def>
<file path="title.txt" action="write">
    <get var="title"/>
</file>

<script>

View Details

Executes scripting code (BeanShell, JavaScript, Groovy)

Example:

script-example.xml 
<script>
    // BeanShell code
    String fullUrl = sys.fullUrl("https://example.com", "/path");
    return fullUrl;
</script>

Extension Processors

<database>

View Details

Database operations (SELECT, INSERT, UPDATE, DELETE)

Key Attributes:

  • driver - JDBC driver
  • url - Connection URL

Example:

database-example.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/mydb"
    username="user"
    password="pass"
    query="SELECT * FROM products WHERE price < ?">
    <db-param>100</db-param>
</database>

<mail>

View Details

Sends email messages

Key Attributes:

  • to - Recipient email
  • subject - Email subject

Example:

mail-example.xml 
<mail 
    to="admin@example.com"
    from="scraper@example.com"
    subject="Scraping Alert"
    smtphost="smtp.example.com"
    smtpport="587">
    <template>Price alert: ${productName} is now $${price}</template>
</mail>

<tokenize>

View Details

Splits text into tokens using delimiters

Key Attributes:

  • delimiters - Delimiter characters

Example:

tokenize-example.xml 
<tokenize delimiters="," trimtokens="true">
    <file path="data.csv" action="read"/>
</tokenize>
