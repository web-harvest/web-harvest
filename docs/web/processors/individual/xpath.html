<xpath>

Extracts data using XPath expressions

Data Processing 2.2.0

Overview

The <xpath> processor is one of the most powerful data extraction tools in Web-Harvest. It uses XPath expressions to navigate and extract specific data from XML documents. XPath provides a flexible and precise way to locate elements, attributes, and text content within XML structures.

Full XPath 3.1 support with advanced expressions
Extract elements, attributes, and text content
Support for namespaces and complex queries
Conditional and positional selection

Attributes

Attribute Type Required Default Description
expression string Yes - XPath expression to evaluate against the input XML
id string No - Unique identifier for the XPath processor

XPath Examples

Basic Element Selection

Extract specific elements from XML:

xpath-basic-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageXml">
    <html-to-xml>
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
  
  <def var="titles">
    <xpath expression="//h1">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <def var="links">
    <xpath expression="//a/@href">
      <get var="pageXml"/>
    </xpath>
  </def>
</config>

Attribute Selection

Extract attributes and their values:

xpath-attributes-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageXml">
    <html-to-xml>
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
  
  <!-- Extract all image sources -->
  <def var="imageSources">
    <xpath expression="//img/@src">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <!-- Extract all class attributes -->
  <def var="classNames">
    <xpath expression="//*[@class]/@class">
      <get var="pageXml"/>
    </xpath>
  </def>
</config>

Conditional Selection

Select elements based on conditions:

xpath-conditions-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageXml">
    <html-to-xml>
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
  
  <!-- Elements with specific class -->
  <def var="highlightedText">
    <xpath expression="//*[@class='highlight']">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <!-- Links with specific text -->
  <def var="downloadLinks">
    <xpath expression="//a[contains(text(), 'Download')]">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <!-- Elements with multiple conditions -->
  <def var="specialDivs">
    <xpath expression="//div[@class='content' and @id]">
      <get var="pageXml"/>
    </xpath>
  </def>
</config>

Advanced XPath Queries

Complex XPath expressions for sophisticated data extraction:

xpath-advanced-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageXml">
    <html-to-xml>
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
  
  <!-- First element of each type -->
  <def var="firstElements">
    <xpath expression="//*[position()=1]">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <!-- Elements with specific text content -->
  <def var="priceElements">
    <xpath expression="//*[contains(text(), '$')]">
      <get var="pageXml"/>
    </xpath>
  </def>
  
  <!-- Parent elements of specific children -->
  <def var="parentDivs">
    <xpath expression="//div[.//img[@alt]]">
      <get var="pageXml"/>
    </xpath>
  </def>
</config>

XPath Reference

Basic Selectors

  • //div - All div elements
  • /html/body - Body element under html
  • //* - All elements
  • //text() - All text nodes

Attribute Selectors

  • //@href - All href attributes
  • //a/@href - href attributes of links
  • //*[@class] - Elements with class attribute
  • //*[@id='main'] - Element with specific id

Conditional Selectors

  • //div[@class='content'] - Divs with specific class
  • //a[contains(@href, 'http')] - Links with http in href
  • //*[position()=1] - First element
  • //*[last()] - Last element

Text Selectors

  • //h1/text() - Text content of h1
  • //*[contains(text(), 'price')] - Elements containing 'price'
  • //*[starts-with(text(), 'Hello')] - Elements starting with 'Hello'
  • //*[normalize-space(text())] - Elements with non-empty text
