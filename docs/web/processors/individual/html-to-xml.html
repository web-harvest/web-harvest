<html-to-xml>

Converts HTML content to well-formed XML using advanced parsing strategies

Web & HTTP 2.2.0

Overview

The <html-to-xml> processor is essential for web scraping as it converts malformed HTML content into well-formed XML that can be processed with XPath and XQuery. This processor uses multiple parsing strategies to handle various HTML formats and provides extensive configuration options for character encoding, entity handling, and XML structure.

Multiple HTML parsing strategies (JSoup, TagSoup, Apache Tika)
Advanced XML character escaping
Unicode character support
Configurable tag and comment handling

Attributes

Attribute Type Required Default Description
advancedxmlescape boolean No false Enable advanced XML character escaping for special characters
specialentities boolean No false Support for special HTML entities like &nbsp;, &copy;, etc.
unicodechars boolean No false Enable Unicode character support for international content
allowmultiwordattributes boolean No false Allow multi-word attribute names in HTML tags
omitunknowntags boolean No false Omit unknown HTML tags from the output XML
omitcomments boolean No false Omit HTML comments from the output XML
omittermlenvelope boolean No false Omit the XML envelope declaration from the output

Examples

Basic HTML Parsing

Simple HTML to XML conversion:

html-to-xml-basic.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageXml">
    <html-to-xml>
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
</config>

Advanced Configuration

HTML parsing with advanced options for better XML output:

html-to-xml-advanced.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="cleanXml">
    <html-to-xml 
      advancedxmlescape="true"
      specialentities="true"
      unicodechars="true"
      omitunknowntags="true"
      omitcomments="true">
      <http url="https://example.com">
      </http>
    </html-to-xml>
  </def>
</config>

Unicode Support

Handling international content with Unicode characters:

html-to-xml-unicode.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="unicodeXml">
    <html-to-xml 
      unicodechars="true"
      advancedxmlescape="true">
      <http url="https://example.com/中文页面">
      </http>
    </html-to-xml>
  </def>
</config>

Entity Handling

Processing HTML with special entities and characters:

html-to-xml-entities.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="entityXml">
    <html-to-xml 
      specialentities="true"
      advancedxmlescape="true"
      allowmultiwordattributes="true">
      <http url="https://example.com/special-chars">
      </http>
    </html-to-xml>
  </def>
</config>
