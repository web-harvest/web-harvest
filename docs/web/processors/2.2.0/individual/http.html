<http>
Processor

HTTP request and response handling

Full-featured HTTP client with authentication, cookies, headers, and connection pooling. Supports GET, POST, PUT, DELETE and all HTTP methods.

Element Name

<http>

Package

org.webharvest.plugin.core

Class

HttpPlugin

Since Version

1.0 (Enhanced in 2.2)

Syntax

Element structure and attributes

http-syntax.xml 
<http url="URL"
      method="GET|POST|PUT|DELETE|HEAD|OPTIONS"
      timeout="milliseconds"
      followRedirects="true|false"
      username="auth-username"
      password="auth-password"
      charset="UTF-8">
  
  <!-- Optional: HTTP headers -->
  <http-header name="User-Agent">WebHarvest Bot</http-header>
  <http-header name="Accept">application/json</http-header>
  
  <!-- Optional: HTTP parameters (POST/PUT) -->
  <http-param name="search">web scraping</http-param>
  <http-param name="limit">100</http-param>
  
  <!-- Optional: Request body -->
  <template>Request body content</template>
  
</http>

Attributes

Configuration options

url

Required: Yes

Type: String (URL)

Description: Target URL to fetch. Supports variable interpolation: ${baseUrl}/api/products

method

Required: No (default: GET)

Type: String

Values: GET, POST, PUT, DELETE, HEAD, OPTIONS, PATCH

Description: HTTP method to use

timeout

Required: No (default: 30000)

Type: Integer (milliseconds)

Description: Connection and read timeout. Use 0 for infinite.

followRedirects

Required: No (default: true)

Type: Boolean

Description: Automatically follow HTTP 3xx redirects

username / password

Required: No

Type: String

Description: Basic HTTP authentication credentials

charset

Required: No (default: UTF-8)

Type: String

Description: Character encoding for request and response

Examples

Common usage patterns

1

Simple GET Request

simple-get.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <!-- Fetch HTML page -->
  <def var="html">
    <http url="https://example.com"/>
  </def>
  
  <!-- Result is stored in 'html' variable -->
  <file path="output.html" action="write">
    <get var="html"/>
  </file>
</config>
2

POST with Parameters

post-form.xml 
<def var="response">
  <http url="https://api.example.com/search" method="POST">
    <http-header name="Content-Type">application/x-www-form-urlencoded</http-header>
    <http-param name="query">web scraping</http-param>
    <http-param name="limit">100</http-param>
  </http>
</def>
3

JSON API with Authentication

api-auth.xml 
<def var="apiResponse">
  <http url="https://api.example.com/v1/data" method="GET">
    <http-header name="Authorization">Bearer ${apiKey}</http-header>
    <http-header name="Accept">application/json</http-header>
  </http>
</def>

<!-- Convert JSON to XML -->
<def var="xmlData">
  <json-to-xml>
    <get var="apiResponse"/>
  </json-to-xml>
</def>
4

With Custom Headers & Timeout

custom-headers.xml 
<def var="page">
  <http url="https://slow-site.com/page" 
        timeout="60000"
        followRedirects="false">
    <http-header name="User-Agent">Mozilla/5.0 WebHarvest/2.2</http-header>
    <http-header name="Accept-Language">en-US,en;q=0.9</http-header>
    <http-header name="Referer">https://google.com</http-header>
  </http>
</def>

Technical Details

Implementation and behavior

Implementation

  • HTTP Client: Apache HttpClient 5.x
  • Connection Pooling: Automatic connection reuse
  • Cookie Management: Automatic cookie handling per session
  • Redirect Handling: Follows 301, 302, 303, 307, 308
  • Thread-Safe: Can be used in parallel executions

Features

  • SSL/TLS Support: HTTPS with certificate validation
  • Compression: Automatic gzip/deflate decompression
  • Charset Detection: Auto-detect encoding from Content-Type
  • Error Handling: Proper exception on timeout/errors
  • Token Tracking: HTTP_REQUEST and HTTP_BYTES tracked

Limitations

  • JavaScript: Does not execute JavaScript (use web-browser plugin)
  • AJAX: Cannot handle dynamic content loaded by AJAX
  • File Upload: Multipart file upload not directly supported
  • WebSocket: No WebSocket protocol support
