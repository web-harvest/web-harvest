<http>

Performs HTTP requests to fetch web content

Web & HTTP 2.2.0

Overview

The <http> processor is one of the most fundamental processors in Web-Harvest. It allows you to make HTTP requests to any web resource and retrieve the response content. This processor supports all standard HTTP methods and provides extensive configuration options for headers, parameters, timeouts, and more.

Supports all HTTP methods (GET, POST, PUT, DELETE, etc.)
Custom headers and parameters
Configurable timeouts and redirects
SSL/TLS support

Attributes

Attribute Type Required Default Description
url string Yes - Target URL to make the HTTP request to
method string No GET HTTP method to use (GET, POST, PUT, DELETE, etc.)
timeout integer No 30000 Request timeout in milliseconds
followredirects boolean No true Whether to follow HTTP redirects automatically
useragent string No - Custom User-Agent string for the request
charset string No UTF-8 Character encoding for the request

Subprocessors

The <http> processor supports the following subprocessors:

<http-header>

Adds custom HTTP headers to the request

Attributes:
  • name - Header name (required)
  • value - Header value (required)

<http-param>

Adds parameters to the request (query string for GET, body for POST)

Attributes:
  • name - Parameter name (required)
  • value - Parameter value (required)

Examples

Basic GET Request

Simple HTTP GET request to fetch a web page:

http-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="pageContent">
    <http url="https://example.com">
    </http>
  </def>
</config>

POST Request with Parameters

HTTP POST request with form parameters:

http-post-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="response">
    <http url="https://api.example.com/submit" method="POST">
      <http-param name="username">john_doe</http-param>
      <http-param name="email">john@example.com</http-param>
      <http-param name="message">Hello World</http-param>
    </http>
  </def>
</config>

Custom Headers

HTTP request with custom headers:

http-headers-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="apiResponse">
    <http url="https://api.example.com/data" method="GET">
      <http-header name="Authorization">Bearer your-token-here</http-header>
      <http-header name="Accept">application/json</http-header>
      <http-header name="User-Agent">WebHarvest/2.2.0</http-header>
    </http>
  </def>
</config>

Advanced Configuration

HTTP request with advanced configuration options:

http-advanced-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="secureResponse">
    <http 
      url="https://secure.example.com/api/data"
      method="GET"
      timeout="60000"
      followredirects="true"
      useragent="Mozilla/5.0 (compatible; WebHarvest/2.2.0)"
      charset="UTF-8">
      <http-header name="Accept">application/json</http-header>
      <http-param name="format">json</http-param>
      <http-param name="limit">100</http-param>
    </http>
  </def>
</config>
