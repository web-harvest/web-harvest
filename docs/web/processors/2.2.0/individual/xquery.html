<xquery>

Advanced data processing using XQuery 3.1

Data Processing 2.2.0

Overview

The <xquery> processor provides powerful data processing capabilities using XQuery 3.1. It allows you to perform complex transformations, aggregations, and queries on XML data with full support for advanced XQuery features including FLWOR expressions, functions, and modules.

Full XQuery 3.1 support with advanced expressions
FLWOR expressions for complex data processing
External parameter support for dynamic queries
Built-in functions and custom function support

Attributes

Attribute Type Required Default Description
id string No - Unique identifier for the XQuery processor

Subprocessors

The <xquery> processor supports the following subprocessors:

<xq-param>

Defines external parameters for the XQuery expression

Attributes:
  • name - Parameter name (required)

<xq-expression>

Contains the XQuery expression to execute

Attributes:
  • None - contains the XQuery code

Examples

Basic XQuery Processing

Simple XQuery transformation of XML data:

xquery-basic-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="xmlData">
    <html-to-xml>
      <http url="https://example.com/products">
      </http>
    </html-to-xml>
  </def>
  
  <def var="processedData">
    <xquery>
      <xq-param name="data">
        <get var="xmlData"/>
      </xq-param>
      <xq-expression>
        <![CDATA[
        declare variable $data as node() external;
        <products>
          {
            for $product in $data//product
            return <item>
              <name>{$product/name}</name>
              <price>{$product/price}</price>
            </item>
          }
        </products>
        ]]>
      </xq-expression>
    </xquery>
  </def>
</config>

FLWOR Expressions

Complex data processing using FLWOR (For, Let, Where, Order by, Return):

xquery-flwor-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="salesData">
    <html-to-xml>
      <http url="https://api.example.com/sales">
      </http>
    </html-to-xml>
  </def>
  
  <def var="topProducts">
    <xquery>
      <xq-param name="sales">
        <get var="salesData"/>
      </xq-param>
      <xq-expression>
        <![CDATA[
        declare variable $sales as node() external;
        <top_products>
          {
            for $product in $sales//product
            let $revenue := $product/price * $product/quantity
            where $revenue > 1000
            order by $revenue descending
            return <product>
              <name>{$product/name}</name>
              <revenue>{$revenue}</revenue>
            </product>
          }
        </top_products>
        ]]>
      </xq-expression>
    </xquery>
  </def>
</config>

External Parameters

Using external parameters for dynamic XQuery processing:

xquery-params-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="minPrice">50</def>
  <def var="maxPrice">500</def>
  <def var="category">electronics</def>
  
  <def var="filteredProducts">
    <xquery>
      <xq-param name="products">
        <get var="productData"/>
      </xq-param>
      <xq-param name="minPrice">
        <get var="minPrice"/>
      </xq-param>
      <xq-param name="maxPrice">
        <get var="maxPrice"/>
      </xq-param>
      <xq-param name="category">
        <get var="category"/>
      </xq-param>
      <xq-expression>
        <![CDATA[
        declare variable $products as node() external;
        declare variable $minPrice as xs:decimal external;
        declare variable $maxPrice as xs:decimal external;
        declare variable $category as xs:string external;
        
        <filtered_products>
          {
            for $product in $products//product
            where $product/@category = $category
              and $product/price >= $minPrice
              and $product/price <= $maxPrice
            return $product
          }
        </filtered_products>
        ]]>
      </xq-expression>
    </xquery>
  </def>
</config>

Advanced XQuery Features

Using advanced XQuery features like functions and grouping:

xquery-advanced-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="salesReport">
    <xquery>
      <xq-param name="data">
        <get var="salesData"/>
      </xq-param>
      <xq-expression>
        <![CDATA[
        declare variable $data as node() external;
        
        declare function local:format-currency($amount as xs:decimal) as xs:string {
          concat("$", format-number($amount, "#,##0.00"))
        };
        
        <sales_report>
          {
            for $category in distinct-values($data//product/@category)
            let $products := $data//product[@category = $category]
            let $total-sales := sum($products/(price * quantity))
            let $avg-price := avg($products/price)
            order by $total-sales descending
            return <category>
              <name>{$category}</name>
              <total_sales>{local:format-currency($total-sales)}</total_sales>
              <avg_price>{local:format-currency($avg-price)}</avg_price>
              <product_count>{count($products)}</product_count>
            </category>
          }
        </sales_report>
        ]]>
      </xq-expression>
    </xquery>
  </def>
</config>
