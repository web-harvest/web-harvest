<tokenize>

Text Processing Processor 2.2.0

The <tokenize> processor splits text into tokens using specified delimiters, making it ideal for parsing CSV data, log files, and other delimited text formats.

Key Features

Flexible Delimiters

Support for single or multiple delimiter characters

Token Trimming

Automatic whitespace trimming from tokens

Empty Token Handling

Configurable handling of empty tokens

XML Output

Tokens are output as XML elements for easy processing

Attributes

Attribute Type Required Description
delimiters String Yes Delimiter characters for splitting text
trimtokens Boolean No Trim whitespace from tokens (default: true)
allowemptytokens Boolean No Allow empty tokens in output (default: false)
id String No Unique identifier for the processor

Subprocessors

Any Processor

The body of tokenize can contain any other processor. The result of the processor execution will be tokenized.

Examples

Basic Text Tokenization

basic-tokenize.xml 
<tokenize delimiters="," trimtokens="true">
    <constant>apple, banana, cherry, date</constant>
</tokenize>

Output:

output.xml 
<tokenize>
    <token>apple</token>
    <token>banana</token>
    <token>cherry</token>
    <token>date</token>
</tokenize>

CSV File Parsing

csv-parsing.xml 
<def var="csvData">
    <file path="products.csv" action="read">
        <file-charset>UTF-8</file-charset>
    </file>
</def>

<def var="csvLines">
    <tokenize delimiters="\n" trimtokens="true">
        <get var="csvData"/>
    </tokenize>
</def>

<loop item="line" index="i">
    <get var="csvLines"/>
    <body>
        <def var="fields">
            <tokenize delimiters="," trimtokens="true">
                <get var="line"/>
            </tokenize>
        </def>
        
        <def var="productName">
            <xpath expression="//token[1]">
                <get var="fields"/>
            </xpath>
        </def>
        
        <def var="productPrice">
            <xpath expression="//token[2]">
                <get var="fields"/>
            </xpath>
        </def>
    </body>
</loop>

Multiple Delimiters

multiple-delimiters.xml 
<tokenize delimiters=",;|" trimtokens="true" allowemptytokens="false">
    <constant>name:John,age:25;city:New York|country:USA</constant>
</tokenize>

Output:

output.xml 
<tokenize>
    <token>name:John</token>
    <token>age:25</token>
    <token>city:New York</token>
    <token>country:USA</token>
</tokenize>

Complex Log File Parsing

log-parsing.xml 
<def var="logData">
    <file path="access.log" action="read">
        <file-charset>UTF-8</file-charset>
    </file>
</def>

<def var="logLines">
    <tokenize delimiters="\n" trimtokens="true">
        <get var="logData"/>
    </tokenize>
</def>

<loop item="logLine" index="i" maxloops="100">
    <get var="logLines"/>
    <body>
        <def var="logFields">
            <tokenize delimiters=" " trimtokens="true">
                <get var="logLine"/>
            </tokenize>
        </def>
        
        <def var="ipAddress">
            <xpath expression="//token[1]">
                <get var="logFields"/>
            </xpath>
        </def>
        
        <def var="timestamp">
            <xpath expression="//token[4]">
                <get var="logFields"/>
            </xpath>
        </def>
        
        <def var="requestUrl">
            <xpath expression="//token[7]">
                <get var="logFields"/>
            </xpath>
        </def>
        
        <file path="parsed_logs.xml" action="append">
            <template>
                <![CDATA[
                <log-entry>
                    <ip>${ipAddress}</ip>
                    <timestamp>${timestamp}</timestamp>
                    <url>${requestUrl}</url>
                </log-entry>
                ]]>
            </template>
        </file>
    </body>
</loop>
