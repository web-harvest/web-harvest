<def var>

Variable Processor 2.2.0

The <def var> processor defines variables with values or processor results for use throughout the Web-Harvest workflow.

Key Features

Variable Definition

Define variables with static values or dynamic processor results

Variable References

Use variables in other processors with ${variableName} syntax

Dynamic Values

Variables can contain results from complex processor chains

Scope Management

Variables are available throughout the current execution context

Attributes

Attribute Type Required Description
var String Yes Variable name (must be unique within scope)
id String No Unique identifier for the processor

Subprocessors

Any Processor

The body of def var can contain any other processor. The result of the processor execution becomes the variable value.

Static Text

Direct text content can be used as the variable value without additional processors.

Examples

Basic Variable Definition

basic-definition.xml 
<def var="baseUrl">https://api.example.com</def>
<def var="apiKey">your-api-key-here</def>
<def var="timeout">30000</def>

<http url="${baseUrl}/products" timeout="${timeout}">
    <http-header name="Authorization">Bearer ${apiKey}</http-header>
</http>

Dynamic Value from HTTP Response

dynamic-value.xml 
<def var="pageContent">
    <http url="https://example.com">
        <http-header name="User-Agent">Web-Harvest Bot</http-header>
    </http>
</def>

<def var="pageTitle">
    <xpath expression="//title">
        <html-to-xml>
            <get var="pageContent"/>
        </html-to-xml>
    </xpath>
</def>

Variable from Processor Chain

processor-chain.xml 
<def var="productData">
    <html-to-xml>
        <http url="https://shop.example.com/product/123">
            <http-header name="Accept">text/html</http-header>
        </http>
    </html-to-xml>
</def>

<def var="productName">
    <xpath expression="//h1[@class='product-title']">
        <get var="productData"/>
    </xpath>
</def>

<def var="productPrice">
    <xpath expression="//span[@class='price']">
        <get var="productData"/>
    </xpath>
</def>

Complex Workflow with Variables

complex-workflow.xml 
<def var="searchQuery">laptop gaming</def>
<def var="searchUrl">
    https://api.example.com/search?q=${searchQuery}&limit=10
</def>

<def var="searchResults">
    <json-to-xml>
        <http url="${searchUrl}">
            <http-header name="Accept">application/json</http-header>
        </http>
    </json-to-xml>
</def>

<def var="productCount">
    <xpath expression="count(//item)">
        <get var="searchResults"/>
    </xpath>
</def>

<file path="search_results.xml" action="write">
    <template>
        <![CDATA[
        <search-results>
            <query>${searchQuery}</query>
            <count>${productCount}</count>
            <results>${searchResults}</results>
        </search-results>
        ]]>
    </template>
</file>
