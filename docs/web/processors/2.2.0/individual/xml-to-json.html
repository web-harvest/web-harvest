<xml-to-json>

Converts XML data to JSON format for API integration

Data Processing 2.2.0

Overview

The <xml-to-json> processor converts XML data into JSON format, making it suitable for modern web APIs and JavaScript applications. This is particularly useful when you need to send data to REST APIs that expect JSON format.

Converts XML elements, attributes, and text to JSON
Handles complex nested XML structures
Preserves XML hierarchy in JSON objects
Compatible with modern web APIs

Attributes

Attribute Type Required Default Description
id string No - Unique identifier for the processor

Examples

Basic XML to JSON Conversion

Simple conversion of XML data to JSON format:

xml-to-json-basic-example.xml
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="xmlData">
    <html-to-xml>
      <http url="https://example.com/products">
      </http>
    </html-to-xml>
  </def>
  
  <def var="jsonData">
    <xml-to-json>
      <get var="xmlData"/>
    </xml-to-json>
  </def>
  
  <!-- Send JSON to API -->
  <def var="apiResponse">
    <http url="https://api.example.com/products" method="POST">
      <http-header name="Content-Type">application/json</http-header>
      <get var="jsonData"/>
    </http>
  </def>
</config>

API Integration

Converting scraped data to JSON for API submission:

xml-to-json-api-example.xml
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="scrapedData">
    <html-to-xml>
      <http url="https://news-site.com/article/123">
      </http>
    </html-to-xml>
  </def>
  
  <!-- Extract specific content -->
  <def var="articleData">
    <template>
      <article>
        <title>
          <xpath expression="//h1">
            <get var="scrapedData"/>
          </xpath>
        </title>
        <content>
          <xpath expression="//div[@class='content']">
            <get var="scrapedData"/>
          </xpath>
        </content>
        <author>
          <xpath expression="//span[@class='author']">
            <get var="scrapedData"/>
          </xpath>
        </author>
        <timestamp>${new java.util.Date()}</timestamp>
      </article>
    </template>
  </def>
  
  <def var="articleJson">
    <xml-to-json>
      <get var="articleData"/>
    </xml-to-json>
  </def>
  
  <!-- Submit to content management API -->
  <def var="cmsResponse">
    <http url="https://cms.example.com/api/articles" method="POST">
      <http-header name="Content-Type">application/json</http-header>
      <http-header name="Authorization">Bearer your-api-key</http-header>
      <get var="articleJson"/>
    </http>
  </def>
</config>

Complex XML Structures

Handling complex nested XML with multiple elements:

xml-to-json-complex-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="orderData">
    <template>
      <order>
        <id>12345</id>
        <customer>
          <name>John Doe</name>
          <email>john@example.com</email>
          <address>
            <street>123 Main St</street>
            <city>New York</city>
            <zip>10001</zip>
          </address>
        </customer>
        <items>
          <item>
            <product>Laptop</product>
            <quantity>1</quantity>
            <price>999.99</price>
          </item>
          <item>
            <product>Mouse</product>
            <quantity>2</quantity>
            <price>29.99</price>
          </item>
        </items>
        <total>1059.97</total>
      </order>
    </template>
  </def>
  
  <def var="orderJson">
    <xml-to-json>
      <get var="orderData"/>
    </xml-to-json>
  </def>
  
  <!-- Send to e-commerce API -->
  <def var="apiResponse">
    <http url="https://api.ecommerce.com/orders" method="POST">
      <http-header name="Content-Type">application/json</http-header>
      <get var="orderJson"/>
    </http>
  </def>
</config>

XML with Attributes

Converting XML with attributes to JSON:

xml-to-json-attributes-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="productData">
    <template>
      <products>
        <product id="1" category="electronics">
          <name>Smartphone</name>
          <price currency="USD">699.99</price>
          <specifications>
            <spec name="screen">6.1 inch</spec>
            <spec name="storage">128GB</spec>
            <spec name="camera">12MP</spec>
          </specifications>
        </product>
        <product id="2" category="electronics">
          <name>Laptop</name>
          <price currency="USD">1299.99</price>
          <specifications>
            <spec name="processor">Intel i7</spec>
            <spec name="ram">16GB</spec>
            <spec name="storage">512GB SSD</spec>
          </specifications>
        </product>
      </products>
    </template>
  </def>
  
  <def var="productsJson">
    <xml-to-json>
      <get var="productData"/>
    </xml-to-json>
  </def>
  
  <!-- Save as JSON file -->
  <file path="products.json" action="write">
    <get var="productsJson"/>
  </file>
</config>
