<database>

Extension Processor 2.2.0

The <database> processor provides JDBC database connectivity for executing SQL queries and managing database operations within Web-Harvest workflows.

Key Features

JDBC Support

Full JDBC driver support for all major databases

Parameterized Queries

Secure parameter binding to prevent SQL injection

Connection Management

Automatic connection pooling and resource management

Result Processing

XML output format for easy data processing

Attributes

Attribute Type Required Description
driver String Yes JDBC driver class name (e.g., com.mysql.cj.jdbc.Driver)
url String Yes Database connection URL
username String Yes Database username
password String Yes Database password
query String Yes SQL query to execute
id String No Unique identifier for the processor

Subprocessors

<db-param>

Defines parameters for parameterized SQL queries. Use multiple db-param elements for multiple parameters.

Examples

Basic SELECT Query

basic-query.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/products"
    username="user"
    password="password"
    query="SELECT id, name, price FROM products WHERE category = 'electronics'">
</database>

Parameterized Query with Security

parameterized-query.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/products"
    username="user"
    password="password"
    query="SELECT * FROM products WHERE price < ? AND category = ?">
    <db-param>100.00</db-param>
    <db-param>electronics</db-param>
</database>

INSERT Operation

insert-operation.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/scraped_data"
    username="user"
    password="password"
    query="INSERT INTO products (name, price, url, scraped_date) VALUES (?, ?, ?, NOW())">
    <db-param>${productName}</db-param>
    <db-param>${productPrice}</db-param>
    <db-param>${productUrl}</db-param>
</database>

Complex JOIN Query

complex-query.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/ecommerce"
    username="user"
    password="password"
    query="SELECT p.name, p.price, c.name as category, s.name as supplier 
           FROM products p 
           JOIN categories c ON p.category_id = c.id 
           JOIN suppliers s ON p.supplier_id = s.id 
           WHERE p.price < ? AND c.name = ?">
    <db-param>500.00</db-param>
    <db-param>electronics</db-param>
</database>
