<mail>

Extension Processor 2.2.0

The <mail> processor provides email sending capabilities using SMTP protocol for notifications, alerts, and data delivery in Web-Harvest workflows.

Key Features

SMTP Support

Full SMTP protocol support for reliable email delivery

Authentication

Support for various authentication methods (PLAIN, LOGIN, CRAM-MD5)

Attachments

Support for file attachments and inline content

Template Support

Dynamic content generation using templates and variables

Attributes

Attribute Type Required Description
to String Yes Recipient email address
from String Yes Sender email address
subject String Yes Email subject line
smtphost String Yes SMTP server hostname
smtpport Integer No SMTP server port (default: 25)
username String No SMTP authentication username
password String No SMTP authentication password
auth String No Authentication method (PLAIN, LOGIN, CRAM-MD5)
tls Boolean No Enable TLS encryption (true/false)
id String No Unique identifier for the processor

Subprocessors

<template>

Defines the email body content with support for variable substitution and dynamic content generation.

<attachment>

Adds file attachments to the email message.

<header>

Adds custom email headers for advanced configuration.

Examples

Basic Email Notification

basic-email.xml 
<mail 
    to="admin@example.com"
    from="scraper@example.com"
    subject="Scraping Completed"
    smtphost="smtp.example.com"
    smtpport="587">
    <template>
        The web scraping process has completed successfully.
        Processed 150 products from the target website.
        Time: ${currentTime}
    </template>
</mail>

Authenticated SMTP Email

authenticated-email.xml 
<mail 
    to="user@example.com"
    from="noreply@example.com"
    subject="Price Alert: ${productName}"
    smtphost="smtp.gmail.com"
    smtpport="587"
    username="your-email@gmail.com"
    password="your-app-password"
    auth="LOGIN"
    tls="true">
    <template>
        <![CDATA[
        <html>
            <body>
                <h2>Price Alert!</h2>
                <p>The price for <strong>${productName}</strong> has changed.</p>
                <p>Old Price: $${oldPrice}</p>
                <p>New Price: $${newPrice}</p>
                <p>Change: ${priceChange}%</p>
                <p><a href="${productUrl}">View Product</a></p>
            </body>
        </html>
        ]]>
    </template>
</mail>

Dynamic Template Email

template-email.xml 
<def var="scrapedData">
    <html-to-xml>
        <http url="https://shop.example.com/products">
            <http-header name="User-Agent">Web-Harvest Bot</http-header>
        </http>
    </html-to-xml>
</def>

<def var="productCount">
    <xpath expression="count(//div[@class='product'])">
        <get var="scrapedData"/>
    </xpath>
</def>

<mail 
    to="manager@example.com"
    from="scraper@example.com"
    subject="Daily Scraping Report - ${currentDate}"
    smtphost="smtp.example.com"
    smtpport="587"
    username="scraper@example.com"
    password="password"
    tls="true">
    <template>
        <![CDATA[
        <html>
            <body>
                <h2>Daily Scraping Report</h2>
                <p>Date: ${currentDate}</p>
                <p>Products Scraped: ${productCount}</p>
                <p>Status: Success</p>
                <h3>Top Products:</h3>
                <ul>
                    <li>Product 1: $99.99</li>
                    <li>Product 2: $149.99</li>
                    <li>Product 3: $199.99</li>
                </ul>
            </body>
        </html>
        ]]>
    </template>
</mail>

Email with Attachments

attachment-email.xml 
<def var="reportData">
    <template>
        <![CDATA[
        <report>
            <title>Weekly Scraping Report</title>
            <date>${currentDate}</date>
            <products>
                <product name="Laptop" price="999.99"/>
                <product name="Phone" price="699.99"/>
                <product name="Tablet" price="399.99"/>
            </products>
        </report>
        ]]>
    </template>
</def>

<file path="weekly_report.xml" action="write">
    <get var="reportData"/>
</file>

<mail 
    to="analyst@example.com"
    from="scraper@example.com"
    subject="Weekly Report - ${currentDate}"
    smtphost="smtp.example.com"
    smtpport="587"
    username="scraper@example.com"
    password="password">
    <template>
        Please find the weekly scraping report attached.
        This report contains data for ${productCount} products.
    </template>
    <attachment path="weekly_report.xml"/>
</mail>
