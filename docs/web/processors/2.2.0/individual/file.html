<file>

File read/write operations for local file system access

File & Data 2.2.0

Overview

The <file> processor provides comprehensive file system operations including reading, writing, and appending content to files. It supports various file formats and encoding options, making it essential for data persistence and file-based workflows.

Read, write, and append file operations
Multiple encoding support (UTF-8, ISO-8859-1, etc.)
Template-based content generation
Automatic directory creation

Attributes

Attribute Type Required Default Description
path string Yes - File path (absolute or relative)
action string No read Operation to perform (read, write, append)
charset string No UTF-8 Character encoding for file operations
createpath boolean No false Create directory path if it doesn't exist

Examples

Reading Files

Read content from various file types:

file-read-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <!-- Read text file -->
  <def var="configData">
    <file path="config.properties" action="read" charset="UTF-8"/>
  </def>
  
  <!-- Read CSV file -->
  <def var="csvData">
    <file path="data/products.csv" action="read" charset="ISO-8859-1"/>
  </def>
  
  <!-- Read JSON file -->
  <def var="jsonData">
    <file path="settings.json" action="read"/>
  </def>
  
  <!-- Read with automatic directory creation -->
  <def var="logData">
    <file 
      path="logs/application.log" 
      action="read" 
      createpath="true"/>
  </def>
</config>

Writing Files

Write content to files with various formats:

file-write-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="scrapedData">
    <html-to-xml>
      <http url="https://example.com/products">
      </http>
    </html-to-xml>
  </def>
  
  <!-- Write XML data -->
  <file path="output/products.xml" action="write" createpath="true">
    <get var="scrapedData"/>
  </file>
  
  <!-- Write CSV data -->
  <file path="output/products.csv" action="write">
    <template>Product,Price,Stock
<loop item="product">
  <get var="scrapedData"//product>
  <template>${product/name},${product/price},${product/stock}
</loop></template>
  </file>
  
  <!-- Write JSON data -->
  <file path="output/products.json" action="write">
    <json-to-xml>
      <get var="scrapedData"/>
    </json-to-xml>
  </file>
</config>

Appending Files

Append content to existing files:

file-append-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="timestamp">
    <script>
      return new java.text.SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new java.util.Date());
    </script>
  </def>
  
  <!-- Append to log file -->
  <file path="logs/scraping.log" action="append" createpath="true">
    <template>[${timestamp}] Scraping completed successfully
</template>
  </file>
  
  <!-- Append CSV data -->
  <file path="data/daily_sales.csv" action="append">
    <template>${date},${product},${amount},${quantity}
</template>
  </file>
  
  <!-- Append with different encoding -->
  <file 
    path="logs/error.log" 
    action="append" 
    charset="UTF-8">
    <template>ERROR: ${errorMessage} at ${timestamp}
</template>
  </file>
</config>

Template Processing

Generate files using templates with variable substitution:

file-template-example.xml 
<config xmlns="http://org.webharvest/schema/2.1/core">
  <def var="reportData">
    <html-to-xml>
      <http url="https://api.example.com/reports">
      </http>
    </html-to-xml>
  </def>
  
  <def var="reportDate">
    <script>
      return new java.text.SimpleDateFormat("yyyy-MM-dd").format(new java.util.Date());
    </script>
  </def>
  
  <!-- Generate HTML report -->
  <file path="reports/daily_report_${reportDate}.html" action="write">
    <template><!DOCTYPE html>
<html>
<head>
    <title>Daily Report - ${reportDate}</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 20px; }
        .header { background: #f0f0f0; padding: 10px; border-radius: 5px; }
        .data-table { width: 100%; border-collapse: collapse; margin-top: 20px; }
        .data-table th, .data-table td { border: 1px solid #ddd; padding: 8px; text-align: left; }
        .data-table th { background-color: #f2f2f2; }
    </style>
</head>
<body>
    <div class="header">
        <h1>Daily Report - ${reportDate}</h1>
        <p>Generated on: ${reportDate}</p>
    </div>
    
    <table class="data-table">
        <thead>
            <tr>
                <th>Product</th>
                <th>Sales</th>
                <th>Revenue</th>
            </tr>
        </thead>
        <tbody>
            <loop item="item">
                <get var="reportData"//item>
                <template>
                    <tr>
                        <td>${item/name}</td>
                        <td>${item/sales}</td>
                        <td>$${item/revenue}</td>
                    </tr>
                </template>
            </loop>
        </tbody>
    </table>
</body>
</html></template>
  </file>
</config>
