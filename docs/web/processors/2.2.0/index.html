Processor Reference

Complete reference for all Web-Harvest processors and their configuration options

New Plugin Architecture in 2.2.0

Web-Harvest introduces a modern plugin architecture with @Plugin annotations, dependency injection, and automatic discovery. All processors are now implemented as plugins with seamless backward compatibility.

Modern Plugin Architecture

@Plugin Annotations

All processors are now implemented as plugins using modern @Plugin annotations for automatic discovery and registration.

Dependency Injection

Built-in dependency injection system for better testability and modularity of processor implementations.

Automatic Discovery

Plugin system automatically discovers and registers all available processors at runtime.

Web & HTTP Processors

Processors for web scraping, HTTP requests, and HTML parsing

<http>

View Details

HTTP client for making web requests with full control over headers, parameters, and response handling

Attributes:

  • url - Target URL (required)
  • method - HTTP method (GET, POST, PUT, DELETE)
  • timeout - Request timeout in milliseconds
  • followredirects - Follow HTTP redirects (true/false)
  • useragent - Custom User-Agent string

Example:

http-example.xml 
<http url="https://example.com" method="GET" timeout="30000">
    <http-header name="Accept">application/json</http-header>
    <http-param name="page">1</http-param>
</http>

<html-to-xml>

View Details

Converts HTML content to well-formed XML for processing with XPath and XQuery

Attributes:

  • advancedxmlescape - Advanced XML escaping
  • specialentities - Handle special HTML entities
  • unicodechars - Unicode character support
  • allowmultiwordattributes - Allow multi-word attributes
  • omitunknowntags - Omit unknown HTML tags
  • omitcomments - Omit HTML comments
  • omittermlenvelope - Omit XML envelope

Example:

html-to-xml-example.xml 
<html-to-xml 
    advancedxmlescape="true" 
    specialentities="true" 
    unicodechars="true">
    <http url="https://example.com"/>
</html-to-xml>

<web-browser>

View Details

Headless web browser for JavaScript-heavy sites using PhantomJS

Attributes:

  • path - Path to PhantomJS executable
  • port - Port for browser communication

Example:

web-browser-example.xml 
<web-browser path="/usr/bin/phantomjs" port="8081">
    <web-browser-load url="https://spa.example.com"/>
    <web-browser-javascript>
        return document.querySelector('.content').innerHTML;
    </web-browser-javascript>
</web-browser>

Data Processing Processors

Processors for data extraction, transformation, and querying

<xpath>

View Details

XPath 3.1 processor for extracting data from XML documents

Attributes:

  • expression - XPath expression (required)
  • id - Unique identifier

Example:

xpath-example.xml 
<xpath expression="//div[@class='product']//h3">
    <html-to-xml>
        <http url="https://shop.example.com"/>
    </html-to-xml>
</xpath>

<xquery>

View Details

Advanced data processing using XQuery 3.1

Attributes:

  • id - Unique identifier

Example:

xquery-example.xml 
<xquery>
    <xq-param name="data">
        <get var="xmlData"/>
    </xq-param>
    <xq-expression>
        <![CDATA[
        declare variable $data as node() external;
        <results>
            {
                for $item in $data//item
                return <item>
                    <name>{$item/name}</name>
                    <price>{$item/price}</price>
                </item>
            }
        </results>
        ]]>
    </xq-expression>
</xquery>

<regexp>

View Details

Regular expression processing for pattern matching and text manipulation

Attributes:

  • pattern - Regular expression pattern (required)
  • action - Action (match, replace, find)
  • replacement - Replacement text for replace action
  • flags - Regex flags (i, m, s, etc.)

Example:

regexp-example.xml 
<regexp pattern="<title>(.*?)</title>" action="match">
    <http url="https://example.com"/>
</regexp>

<json-to-xml>

View Details

Converts JSON data to XML format for further processing

Attributes:

  • id - Unique identifier

Example:

json-to-xml-example.xml 
<json-to-xml>
    <http url="https://api.example.com/data"/>
</json-to-xml>

<xml-to-json>

View Details

Converts XML data to JSON format for API integration

Attributes:

  • id - Unique identifier

Example:

xml-to-json-example.xml 
<xml-to-json>
    <get var="xmlData"/>
</xml-to-json>

File Operations Processors

Processors for file I/O, templates, and text processing

<file>

View Details

File operations for reading, writing, and managing files

Attributes:

  • path - File path (required)
  • action - Action (read, write, append)
  • charset - Character encoding
  • createpath - Create directory path if not exists

Example:

file-example.xml 
<file path="output.xml" action="write" charset="UTF-8">
    <template>
        <![CDATA[
        <results>
            <title>${title}</title>
            <content>${content}</content>
        </results>
        ]]>
    </template>
</file>

Control Flow Processors

Processors for loops, conditions, and program flow control

<loop>

View Details

Iterates over collections and executes body for each item

Attributes:

  • item - Variable name for current item
  • index - Variable name for current index
  • maxloops - Maximum number of iterations

Example:

loop-example.xml 
<loop item="product" index="i" maxloops="10">
    <list>
        <constant>Product 1</constant>
        <constant>Product 2</constant>
    </list>
    <body>
        <def var="productName">
            <get var="product"/>
        </def>
    </body>
</loop>

Variable Processors

Processors for variable management and data storage

<def var>

View Details

Defines variables with values or processor results

Attributes:

  • var - Variable name (required)

Example:

def-var-example.xml 
<def var="productUrl">https://shop.example.com/product/123</def>
<def var="productData">
    <html-to-xml>
        <http url="${productUrl}"/>
    </html-to-xml>
</def>

<get var>

View Details

Retrieves the value of a previously defined variable

Attributes:

  • var - Variable name (required)

Example:

get-var-example.xml 
<def var="title">
    <xpath expression="//title">
        <get var="pageContent"/>
    </xpath>
</def>
<file path="title.txt" action="write">
    <get var="title"/>
</file>

Extension Processors

Processors for database, email, FTP, and other external services

<database>

View Details

Database operations with JDBC support

Attributes:

  • driver - JDBC driver class
  • url - Database connection URL
  • username - Database username
  • password - Database password
  • query - SQL query to execute

Example:

database-example.xml 
<database 
    driver="com.mysql.cj.jdbc.Driver"
    url="jdbc:mysql://localhost:3306/mydb"
    username="user"
    password="pass"
    query="SELECT * FROM products WHERE price < ?">
    <db-param>100</db-param>
</database>

<mail>

View Details

Email sending with SMTP support

Attributes:

  • to - Recipient email address
  • from - Sender email address
  • subject - Email subject
  • smtphost - SMTP server host
  • smtpport - SMTP server port

Example:

mail-example.xml 
<mail 
    to="admin@example.com"
    from="scraper@example.com"
    subject="Scraping Alert"
    smtphost="smtp.example.com"
    smtpport="587">
    <template>Price alert: ${productName} is now $${price}</template>
</mail>

<tokenize>

View Details

Text tokenization for parsing delimited data

Attributes:

  • delimiters - Delimiter characters
  • trimtokens - Trim whitespace from tokens
  • allowemptytokens - Allow empty tokens

Example:

tokenize-example.xml 
<tokenize delimiters="," trimtokens="true">
    <file path="data.csv" action="read"/>
</tokenize>
