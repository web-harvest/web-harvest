Our Journey

2006

The Beginning

Vladimir Nikic creates WebHarvest as an open-source solution for web data extraction. The project quickly gains traction in the Java community.

2007-2015

Community Growth

Active development with contributions from Alexander Wajda, Piotr Dyraga, and Maciej Czapiewski. WebHarvest becomes a trusted tool for web scraping projects worldwide.

2024

Major Modernization

Robert Bala leads comprehensive refactoring: migration to Java 11+, complete architecture redesign, modern HTTP client (Apache HttpClient 5), and enhanced test coverage.

2025

Web-Based IDE & Beyond

Launch of modern web-based IDE with Monaco editor, WebSocket streaming, session management, and token tracking. WebHarvest enters a new era of developer experience.
