An optional process adapter for the WebHarvest Core runtime

The current CLI implementation is a one-shot batch runner. Its arguments, execution contract and distribution are under review. This historical page is not a guarantee that every feature described below is supported by the current main branch.

Current architecture and support status

Core first; process execution is an optional integration boundary.

Primary integration: embed the WebHarvest Core runtime through its Java API.

CLI role: the current module is a one-shot headless batch runner. Its argument handling, exit behavior, dependency bundle and compatibility contract are being audited.

Not established: parallel multi-configuration orchestration, a long-running server, a scheduler, a job manager or a first-party container distribution.

Deployment: a separate process can be useful for isolation, non-Java callers and host-managed batch jobs. Docker is optional packaging, not a product requirement.

See the CLI and headless execution decision for the rationale, evidence and compatibility gates.

No current standalone CLI release is announced on this page. Consult the canonical GitHub repository and its release-readiness documentation.
