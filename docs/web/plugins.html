Available External Plugins

Production-ready extensions for common use cases

Database Plugin

Module: webharvest-database

Execute SQL queries, connect to any JDBC database with connection pooling.

View Documentation

Features:

  • Named connections with pooling
  • Support for all JDBC databases
  • Inline or external SQL
  • Result mapping to XML

Example:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-mail</artifactId>
  <version>2.2.0</version>
</dependency>

FTP Plugin

Module: webharvest-ftp

Upload/download files via FTP and FTPS with directory operations.

View Documentation

Features:

  • FTP and FTPS support
  • Upload/download files
  • Directory listing
  • Passive/active mode

Example:

ftp-example.xml 
<ftp 
    host="ftp.example.com"
    username="user"
    password="password"
    action="put"
    remoteFile="/data/report.xml"
    localFile="report.xml"/>

<!-- Download -->
<ftp 
    host="ftp.example.com"
    username="user"
    password="password"
    action="get"
    remoteFile="/data/input.csv"
    localFile="input.csv"/>

Maven:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-ftp</artifactId>
  <version>2.2.0</version>
</dependency>

Mail Plugin

Module: webharvest-mail

Send emails via SMTP with HTML, attachments, and authentication.

View Documentation

Features:

  • SMTP email sending
  • HTML and plain text emails
  • Gmail, Office365, custom SMTP
  • Authentication support

Example:

mail-example.xml 
<mail smtp-host="smtp.gmail.com"
      smtp-port="587"
      username="user@gmail.com"
      password="app-password"
      from="scraper@example.com"
      to="admin@example.com"
      subject="Scraping Report">
    
    Scraping completed at ${_date}
    Products found: ${productCount}
</mail>

Maven:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-mail</artifactId>
  <version>2.2.0</version>
</dependency>

ZIP Plugin

Module: webharvest-zip

Create and extract ZIP archives with compression options.

View Documentation

Features:

  • Create ZIP archives
  • Extract ZIP contents
  • List archive contents
  • Compression levels

Example:

zip-example.xml 
<!-- Create archive -->
<zip path="archive.zip" action="create">
  <file path="file1.txt" action="read"/>
  <file path="file2.txt" action="read"/>
</zip>

<!-- Extract archive -->
<zip path="archive.zip" 
     action="extract" 
     destination="output/"/>

Maven:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-zip</artifactId>
  <version>2.2.0</version>
</dependency>

Web Browser Plugin

Module: webharvest-webbrowser

Automated browser interactions for JavaScript-heavy sites.

View Documentation

Features:

  • Headless browser automation
  • JavaScript execution
  • DOM interaction
  • Screenshot capture

Example:

browser-example.xml 
<web-browser 
    url="https://dynamic-site.com"
    waitForElement=".loaded">
  <!-- Browser actions -->
  <click selector=".load-more"/>
  <wait milliseconds="2000"/>
  <extract selector=".items" var="items"/>
</web-browser>

Maven:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-webbrowser</artifactId>
  <version>2.2.0</version>
</dependency>

How the Plugin System Works

Auto-discovery, registration, and dependency injection

Auto-Discovery

  • Classpath Scanning: Plugins discovered automatically at startup
  • Annotations: @Autoscanned + @Definition
  • No Configuration: Just add JAR to classpath
  • Namespace Support: Multiple XML namespaces

Dependency Injection

  • Guice Integration: Full DI support via @Inject
  • Service Location: InjectorHelper for manual lookup
  • HttpService: Shared HTTP client with connection pooling
  • Lifecycle Management: Automatic initialization and cleanup

XSD Generation

  • Automatic Schemas: XSD generated from plugin annotations
  • IDE Support: Auto-completion in XML editors
  • Validation: Compile-time configuration checking
  • Documentation: Self-documenting plugins

Building Custom Plugins

Step-by-step guide to creating your own

1

Maven / Gradle Setup

Maven: Add dependency to pom.xml:

pom.xml 
<dependency>
  <groupId>org.webharvest</groupId>
  <artifactId>webharvest-core</artifactId>
  <version>2.2.0</version>
</dependency>

Gradle: Add to build.gradle:

build.gradle 
dependencies {
    implementation 'org.webharvest:webharvest-core:2.2.0'
}
2

Create Plugin Class

Extend AbstractProcessor and add annotations:

Example.java 
@Autoscanned
@TargetNamespace({"http://web-harvest.sourceforge.net/schema/1.0/config"})
@Definition(
    value = "my-plugin",
    validAttributes = {"attr1", "attr2"},
    requiredAttributes = "attr1"
)
public class MyPluginProcessor extends AbstractProcessor<MyPluginDef> {
    
    @Override
    public Variable execute(DynamicScopeContext context) 
            throws InterruptedException {
        String attr1 = BaseTemplater.evaluateToString(
            elementDef.getAttr1(), null, context);
        
        // Plugin logic
        String result = processData(attr1);
        
        return new NodeVariable(result);
    }
}
3

Create Definition Class

Define plugin attributes and validation:

Example.java 
public class MyPluginDef extends ProcessorDefinition {
    private String attr1;
    private String attr2;
    
    public String getAttr1() { return attr1; }
    public void setAttr1(String attr1) { this.attr1 = attr1; }
    
    public String getAttr2() { return attr2; }
    public void setAttr2(String attr2) { this.attr2 = attr2; }
}
4

Package & Deploy

Build JAR and add to WebHarvest classpath:

terminal 
mvn clean package
cp target/my-plugin-1.0.0.jar $WEBHARVEST_HOME/lib/

# Plugin is auto-discovered on next run!

Use in configurations:

config.xml 
<my-plugin attr1="value">
  <http url="https://example.com"/>
</my-plugin>
