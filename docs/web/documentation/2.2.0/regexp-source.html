<regexp-source>

Regexp source text definition

Core v2.2.0

Overview

The processor defines the text to match against. Must be used as a child element of .

Usage Examples

Usage Examples

example-1.xml 
<regexp>
  <regexp-pattern>\\d{3}-\\d{3}-\\d{4}</regexp-pattern>
  <regexp-source>${textWithPhoneNumbers}</regexp-source>
</regexp>

Parameters

  • source: (required): The text to match against (as element content)
  • Variable Support: : Can use ${var} for dynamic content

Important Notes

  • Parent Element: : Must be used as child of element
  • Text Input: : Provides the text content for pattern matching
  • Variable Substitution: : Supports ${var} syntax for dynamic content
  • Multiple Matches: : Can match multiple occurrences in source text
