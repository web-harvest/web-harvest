🎨 CSS Selectors Guide

Modern HTML querying with CSS selectors in WebHarvest 2.2.0

✨ Bug #13 Enhancement: CSS Selector Support

What's New: WebHarvest now supports CSS selectors as a modern, simpler alternative to XPath for HTML querying!

  • ✅ W3C Standard syntax (not proprietary)
  • ✅ Simpler than XPath: a.link vs //a[@class='link']
  • ✅ Familiar to web developers (jQuery, CSS)
  • ✅ Powered by jsoup library (mature, 14+ years)
  • ✅ Backward compatible (XPath still works!)

📚 Quick Start

Basic Usage

<!-- CSS Selector Mode: type="css" -->
<xpath type="css" expression="a.link">
    <html-to-xml>
        <http url="https://example.com"/>
    </html-to-xml>
</xpath>

<!-- XPath Mode (default): no type attribute -->
<xpath expression="//a[@class='link']">
    <html-to-xml>
        <http url="https://example.com"/>
    </html-to-xml>
</xpath>

🆚 CSS vs XPath Comparison

Task CSS Selector XPath
Select by class a.link //a[@class='link']
Select by ID #main-content //*[@id='main-content']
Nested selection .product h3 //div[@class='product']//h3
First child li:first-child //li[1]
Attribute selector input[type='text'] //input[@type='text']
Direct child div > p //div/p

Verdict: CSS Selectors are simpler and more readable for HTML!

💡 Real-World Examples

Example 1: E-commerce Product Scraping

<config>
    <!-- Scrape product names -->
    <var-def name="products">
        <xpath type="css" expression=".product h3.title">
            <html-to-xml>
                <http url="https://shop.example.com/products"/>
            </html-to-xml>
        </xpath>
    </var-def>
    
    <!-- Scrape prices -->
    <var-def name="prices">
        <xpath type="css" expression=".product .price">
            <html-to-xml>
                <http url="https://shop.example.com/products"/>
            </html-to-xml>
        </xpath>
    </var-def>
    
    <!-- Display results -->
    <loop item="product" index="i">
        <list>${products}</list>
        <var-def name="price">
            <script>context.getVar("prices").toList().get(i)</script>
        </var-def>
        <echo>${product}: ${price}</echo>
    </loop>
</config>

What it does: Extracts product names and prices from an e-commerce site using simple CSS selectors!

Example 2: News Article Titles

<var-def name="headlines">
    <xpath type="css" expression="article > h2.headline">
        <html-to-xml>
            <http url="https://news.example.com"/>
        </html-to-xml>
    </xpath>
</var-def>

CSS Selector: article > h2.headline = "H2 with class 'headline' that is a direct child of 'article'"

Example 3: Navigation Links

<var-def name="nav_links">
    <xpath type="css" expression="nav.main-menu a[href]">
        <html-to-xml>
            <http url="https://example.com"/>
        </html-to-xml>
    </xpath>
</var-def>

CSS Selector: nav.main-menu a[href] = "Links with href inside nav with class 'main-menu'"

📖 CSS Selector Syntax Reference

Basic Selectors

Selector Description Example
element Select by tag name a = all links
.class Select by class .link = class="link"
#id Select by ID #header = id="header"
[attribute] Select by attribute [href] = has href
[attr=value] Select by attribute value [type='text']

Combinators

Combinator Description Example
A B Descendant (any level) div p = p inside div
A > B Direct child div > p = direct child p
A + B Adjacent sibling h2 + p = p after h2
A, B Multiple selectors h1, h2, h3 = all headings

Pseudo-Selectors

Pseudo-Selector Description Example
:first-child First child element li:first-child
:last-child Last child element li:last-child
:nth-child(n) Nth child element li:nth-child(2)
:not(selector) Negation a:not(.external)

⚖️ When to Use CSS vs XPath?

✅ Use CSS Selectors When:

  • Scraping modern HTML websites
  • Selecting by class, ID, or simple attributes
  • You want readable, maintainable code
  • Team knows jQuery/CSS (low learning curve)
  • Simple hierarchical selections

⚡ Use XPath When:

  • Working with XML (not HTML)
  • Need text() content selection
  • Complex predicates (conditions)
  • Need parent/ancestor selection
  • Following/preceding sibling logic

🔧 Migration Guide

Migrating existing XPath configurations to CSS selectors is easy:

Before (XPath):

<xpath expression="//div[@class='product']//h3">
    <html-to-xml>${response}</html-to-xml>
</xpath>

After (CSS Selectors):

<xpath type="css" expression=".product h3">
    <html-to-xml>${response}</html-to-xml>
</xpath>

✅ Simpler, more readable, same result!

🎓 Best Practices

  1. Start simple: Use basic selectors first (.class, #id)
  2. Test in browser: Use browser DevTools to test CSS selectors
  3. Be specific: .product h3.title is better than just h3
  4. Use pseudo-selectors: :first-child is cleaner than index logic
  5. Mix with XPath when needed: Use the best tool for each job!

📊 Performance Notes

CSS Selectors performance:

  • ✅ Fast for class/ID selections
  • ✅ Efficient with jsoup's optimized parser
  • ✅ Same speed as XPath for simple queries
  • ⚠️ For very complex logic, XPath may be faster

🐛 Troubleshooting

Problem: Selector returns empty results

Solution:

  • Test selector in browser DevTools first
  • Check if HTML is valid (use <html-to-xml>)
  • Verify class/ID names are correct
  • Use broader selector, then narrow down

Problem: Need to select by text content

Solution: Use XPath for text() selections - CSS can't do this:

<!-- CSS can't select by text, use XPath: -->
<xpath expression="//a[text()='Click Here']">
    <html-to-xml>${response}</html-to-xml>
</xpath>
