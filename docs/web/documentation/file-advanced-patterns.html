📁 File Advanced Patterns

CSV splitting, file caching, and age-based conditional reading

Solutions for #2 File command improvements

← Back to Documentation

📋 Overview

This guide demonstrates advanced file processing patterns that solve common use cases:

  • CSV/Text Splitting - Read file and split into lines or fields
  • File Age Checking - Conditional processing based on file modification time
  • Simple Caching - Reuse recent file results, refresh if stale

💡 Good News: WebHarvest already provides all necessary tools for these patterns using <tokenize>, <script>, and <if> processors!

Pattern 1: Split File into Lines (CSV Processing)

Use Case: Read CSV file and process each line separately

Solution: File + Tokenize

<!-- Read CSV file --> <def var="csvContent"> <file path="data.csv" action="read"/> </def> <!-- Split by newline into list of lines --> <def var="lines"> <tokenize delimiters="\n">${csvContent}</tokenize> </def> <!-- Process each line --> <loop item="line" index="i"> ${lines} <!-- Skip header line --> <if condition="${i > 0}"> <!-- Split line into fields --> <def var="fields"> <tokenize delimiters=",">${line}</tokenize> </def> <!-- Process CSV fields --> <file path="output.txt" action="append"> Line ${i}: ${line} </file> </if> </loop>

Compact Version: Direct Loop

<!-- Even simpler: Loop can split directly --> <loop item="line" index="i" delimiter="\n"> <file path="data.csv" action="read"/> <!-- Each iteration gets one line --> <if condition="${i > 0}"> <!-- Process line --> </if> </loop>

Pattern 2: Conditional Read Based on File Age (Caching)

Use Case: Only process file if it's newer than a certain age (e.g., cache for 2 hours)

Solution: Script + If Condition

<!-- Check if cache file is fresh (younger than 2 hours) --> <def var="cacheFile">cache/data.txt</def> <def var="maxAgeMs">7200000</def> <!-- 2 hours = 2 * 60 * 60 * 1000 --> <def var="isCacheFresh"> <script> var file = new java.io.File(context.getVar('cacheFile').toString()); if (!file.exists()) { false; // File doesn't exist - not fresh } else { var ageMs = new Date().getTime() - file.lastModified(); var maxAge = parseInt(context.getVar('maxAgeMs')); ageMs < maxAge; // Fresh if age less than max } </script> </def> <if condition="${isCacheFresh}"> <!-- ✅ Cache is fresh - read from file --> <def var="data"> <file path="${cacheFile}" action="read"/> </def> </if> <else> <!-- ❌ Cache stale or missing - fetch fresh data --> <def var="data"> <http url="https://api.example.com/data"/> </def> <!-- Update cache --> <file path="${cacheFile}" action="write"> ${data} </file> </else>

Reusable Cache Function

<!-- Define cache helper function --> <function name="cachedHttp"> <return> <def var="url"><call-param name="url"/></def> <def var="cachePath"><call-param name="cachePath"/></def> <def var="maxAgeMs"><call-param name="maxAgeMs"/></def> <!-- Check cache freshness --> <def var="useCached"> <script> var file = new java.io.File(context.getVar('cachePath').toString()); if (!file.exists()) { false; } else { var age = new Date().getTime() - file.lastModified(); var maxAge = parseInt(context.getVar('maxAgeMs')); age < maxAge; } </script> </def> <if condition="${useCached}"> <file path="${cachePath}" action="read"/> </if> <else> <def var="fresh"> <http url="${url}"/> </def> <file path="${cachePath}" action="write">${fresh}</file> ${fresh} </else> </return> </function> <!-- Use cached HTTP --> <def var="data"> <call name="cachedHttp"> <call-param name="url">https://api.example.com/data</call-param> <call-param name="cachePath">cache/api-data.txt</call-param> <call-param name="maxAgeMs">3600000</call-param> <!-- 1 hour --> </call> </def>

Pattern 3: Human-Readable Time Notation

Use Case: Express age limits in readable format like "d:2,h:3,m:30" (2 days, 3 hours, 30 minutes)

Solution: Script Helper Function

<!-- Parse time notation: "d:2,h:3,m:30,s:45" --> <function name="parseTimeNotation"> <return> <script> var notation = context.getVar('timeNotation').toString(); var totalMs = 0; var parts = notation.split(','); for (var i = 0; i < parts.length; i++) { var part = parts[i].trim(); var kv = part.split(':'); if (kv.length == 2) { var unit = kv[0].trim(); var value = parseInt(kv[1].trim()); if (unit == 'd') totalMs += value * 24 * 60 * 60 * 1000; // days else if (unit == 'h') totalMs += value * 60 * 60 * 1000; // hours else if (unit == 'm') totalMs += value * 60 * 1000; // minutes else if (unit == 's') totalMs += value * 1000; // seconds else if (unit == 'ms') totalMs += value; // milliseconds } } totalMs; // Return total milliseconds </script> </return> </function> <!-- Use it: Check if file younger than "d:2,h:3,m:30" --> <def var="timeNotation">d:2,h:3,m:30</def> <def var="maxAgeMs"> <call name="parseTimeNotation"/> </def> <def var="isFileYoung"> <script> var file = new java.io.File('cache/data.txt'); if (!file.exists()) { false; } else { var ageMs = new Date().getTime() - file.lastModified(); var maxAge = parseInt(context.getVar('maxAgeMs')); ageMs < maxAge; } </script> </def> <if condition="${isFileYoung}"> <!-- File is young - read cache --> </if> <else> <!-- File is old - refresh --> </else>

Pattern 4: Complete CSV Processing with Caching

Use Case: Process CSV file with line splitting and intelligent caching

<config> <!-- Configuration --> <def var="dataFile">data/products.csv</def> <def var="cacheMaxAge">3600000</def> <!-- 1 hour --> <!-- Check if file is fresh (younger than 1 hour) --> <def var="needsRefresh"> <script> var file = new java.io.File(context.getVar('dataFile').toString()); if (!file.exists()) { true; // File doesn't exist - needs creation } else { var ageMs = new Date().getTime() - file.lastModified(); var maxAge = parseInt(context.getVar('cacheMaxAge')); ageMs >= maxAge; // Needs refresh if age exceeds limit } </script> </def> <if condition="${needsRefresh}"> <!-- Fetch fresh data from API --> <def var="csvData"> <http url="https://api.example.com/products.csv"/> </def> <!-- Update cache file --> <file path="${dataFile}" action="write"> ${csvData} </file> </if> <else> <!-- Use cached data --> <def var="csvData"> <file path="${dataFile}" action="read"/> </def> </else> <!-- Split CSV into lines and process --> <loop item="line" index="i" delimiter="\n"> ${csvData} <!-- Skip header (line 0) --> <if condition="${i > 0}"> <!-- Split line into fields --> <loop item="field" index="fieldIdx" delimiter=","> ${line} <!-- Process each field --> <def var="field${fieldIdx}">${field}</def> </loop> <!-- Now have: field0, field1, field2, etc. --> <file path="processed/product-${i}.json" action="write"> { "id": "${field0}", "name": "${field1}", "price": "${field2}" } </file> </if> </loop> </config>

Pattern 5: Multi-Level Cache with TTL

Use Case: Implement sophisticated caching with different TTLs for different data types

<!-- Reusable cache function with TTL --> <function name="cachedFetch"> <return> <def var="sourceUrl"><call-param name="url"/></def> <def var="cachePath"><call-param name="cachePath"/></def> <def var="ttlHours"><call-param name="ttlHours"/></def> <def var="ttlMs"> <script> parseInt(context.getVar('ttlHours')) * 60 * 60 * 1000; </script> </def> <def var="cacheValid"> <script> var file = new java.io.File(context.getVar('cachePath').toString()); if (!file.exists()) { false; } else { var age = new Date().getTime() - file.lastModified(); var ttl = parseInt(context.getVar('ttlMs')); age < ttl; } </script> </def> <if condition="${cacheValid}"> <!-- Cache hit --> <file path="${cachePath}" action="read"/> </if> <else> <!-- Cache miss - fetch and update --> <def var="freshData"> <http url="${sourceUrl}"/> </def> <file path="${cachePath}" action="write">${freshData}</file> ${freshData} </else> </return> </function> <!-- Use with different TTLs --> <def var="productData"> <call name="cachedFetch"> <call-param name="url">https://api.example.com/products</call-param> <call-param name="cachePath">cache/products.json</call-param> <call-param name="ttlHours">24</call-param> <!-- 24h cache --> </call> </def> <def var="priceData"> <call name="cachedFetch"> <call-param name="url">https://api.example.com/prices</call-param> <call-param name="cachePath">cache/prices.json</call-param> <call-param name="ttlHours">1</call-param> <!-- 1h cache (prices change often) --> </call> </def>

Pattern 6: Production-Ready File Caching System

Complete solution with file age checking, CSV splitting, error handling

<config> <!-- Configuration --> <def var="apiUrl">https://api.example.com/products.csv</def> <def var="cacheFile">cache/products.csv</def> <def var="cacheMaxAge">d:1</def> <!-- 1 day --> <!-- Parse time notation --> <def var="maxAgeMs"> <script> var notation = context.getVar('cacheMaxAge').toString(); var totalMs = 0; var parts = notation.split(','); for (var i = 0; i < parts.length; i++) { var kv = parts[i].trim().split(':'); if (kv.length == 2) { var unit = kv[0].trim(); var val = parseInt(kv[1].trim()); if (unit == 'd') totalMs += val * 24 * 60 * 60 * 1000; else if (unit == 'h') totalMs += val * 60 * 60 * 1000; else if (unit == 'm') totalMs += val * 60 * 1000; else if (unit == 's') totalMs += val * 1000; else if (unit == 'ms') totalMs += val; } } totalMs; </script> </def> <!-- Check cache age --> <def var="cacheIsYoung"> <script> var file = new java.io.File(context.getVar('cacheFile').toString()); if (!file.exists()) { false; } else { var age = new Date().getTime() - file.lastModified(); var maxAge = parseInt(context.getVar('maxAgeMs')); // Log cache age var ageHours = age / (60 * 60 * 1000); var maxHours = maxAge / (60 * 60 * 1000); print('Cache age: ' + ageHours.toFixed(1) + 'h (max: ' + maxHours.toFixed(1) + 'h)'); age < maxAge; } </script> </def> <!-- Fetch data (cached or fresh) --> <if condition="${cacheIsYoung}"> <def var="csvData"> <file path="${cacheFile}" action="read"/> </def> <file path="scraper.log" action="append"> [${_date}] Cache HIT - using cached data </file> </if> <else> <try> <def var="csvData"> <http url="${apiUrl}"/> </def> <file path="${cacheFile}" action="write">${csvData}</file> <file path="scraper.log" action="append"> [${_date}] Cache MISS - fetched fresh data </file> </try> <catch> <!-- Fallback to stale cache if fetch fails --> <def var="csvData"> <file path="${cacheFile}" action="read"/> </def> <file path="scraper.log" action="append"> [${_date}] Fetch FAILED - using stale cache </file> </catch> </else> <!-- Split CSV and process --> <loop item="line" index="lineNum" delimiter="\n"> ${csvData} <if condition="${lineNum > 0}"> <!-- Skip header --> <!-- Split line into fields --> <def var="fields"> <tokenize delimiters=",">${line}</tokenize> </def> <!-- Access fields as list items --> <loop item="field" index="colIdx"> ${fields} <def var="col${colIdx}">${field}</def> </loop> <!-- Save processed data --> <file path="output/product-${lineNum}.json" action="write"> { "id": "${col0}", "name": "${col1}", "price": "${col2}", "stock": "${col3}" } </file> </if> </loop> </config>

✨ Benefits of These Patterns

  • ✅ CSV Splitting - Tokenize + Loop provides flexible text splitting
  • ✅ File Age Checking - Script with File.lastModified() enables caching
  • ✅ Reusable Functions - Cache logic encapsulated for reuse
  • ✅ Human-Readable TTL - "d:2,h:3,m:30" notation via helper function
  • ✅ Error Handling - Try/Catch for graceful failover to stale cache
  • ✅ No Native Changes Needed - Works with existing processors

📊 Feature Request vs. Current Solution

Requested Feature 1: SPLIT attribute

<!-- User wanted: --> <file action="read" split="\n" path="data.csv"/> <!-- Would return list of lines --> <!-- Current solution (equally simple): --> <loop item="line" delimiter="\n"> <file path="data.csv" action="read"/> <!-- Process each line --> </loop> <!-- Or: --> <def var="lines"> <tokenize delimiters="\n"> <file path="data.csv" action="read"/> </tokenize> </def>

Requested Feature 2: YOUNGERTHAN attribute

<!-- User wanted: --> <file action="read" youngerthan="d:2,s:30,ms:10" path="cache.txt"> <!-- Execute this body if file is older than limit --> <http url="..."/> </file> <!-- Current solution (more flexible): --> <def var="cacheIsYoung"> <script> var file = new java.io.File('cache.txt'); if (!file.exists()) false; else { var age = new Date().getTime() - file.lastModified(); age < (2*24*60*60*1000 + 30*1000 + 10); // d:2,s:30,ms:10 } </script> </def> <if condition="${cacheIsYoung}"> <def var="data"><file path="cache.txt" action="read"/></def> </if> <else> <def var="data"><http url="..."/></def> <file path="cache.txt" action="write">${data}</file> </else>

⚠️ Design Decision: While adding split and youngerthan attributes to FilePlugin is possible, the current approach offers:

  • More flexibility (custom logic via Script)
  • Better composability (separate concerns: read vs. process)
  • Easier debugging (explicit steps)
  • No new syntax to learn (uses existing processors)
