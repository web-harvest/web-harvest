⚙️ Settings & Command-Line Interface

Unified configuration system for WebHarvest CLI and GUI

✅ New in v2.2.1 Bug #39 Fix
← Back to Documentation

📋 Overview

Problem Solved: Previously, WebHarvest required maintaining separate configurations for GUI (webharvest.properties) and CLI (command-line arguments). This caused duplication and maintenance burden.

Solution: WebHarvest v2.2.1 introduces a unified settings system where both GUI and CLI share the same configuration source, with CLI arguments able to override file settings when needed.

🚀 Quick Start

1. Create Settings File

Create ~/.webharvest/webharvest.properties:

# WebHarvest Settings workdir=/projects/scraping debug=false loglevel=INFO proxyhost=proxy.company.com proxyport=8080

2. Run CLI

Settings are automatically loaded:

java -jar webharvest-cli.jar -c scraper.xml

3. Override When Needed

Command-line arguments override file settings:

java -jar webharvest-cli.jar -c scraper.xml -w /tmp --loglevel DEBUG

📄 Settings File

Discovery Locations

WebHarvest automatically searches for settings in this order:

  1. System Property: -Dwebharvest.settings=/path/to/settings.properties
  2. User Home: ~/.webharvest/webharvest.properties
  3. Current Directory: ./webharvest.properties

Supported Properties

Property Description Example
workdir Working directory for file operations /projects/scraping
debug Enable debug mode true or false
loglevel Logging level TRACE, DEBUG, INFO, WARN, ERROR, FATAL
logpropsfile Custom Log4j properties file /etc/log4j.properties
proxyhost HTTP proxy server host proxy.company.com
proxyport HTTP proxy server port 8080
proxyuser Proxy authentication username john.doe
proxypassword Proxy authentication password secret123
proxynthost NT proxy host (for NTLM authentication) WORKSTATION01
proxyntdomain NT proxy domain COMPANY
dbdrivers Database JDBC drivers (comma-separated) org.postgresql.Driver,com.mysql.cj.jdbc.Driver
plugins Plugin packages to auto-scan com.example.plugins,org.custom.webharvest

💻 Command-Line Arguments

Modern Format (Recommended)

WebHarvest v2.2.1 uses Apache Commons CLI for modern, intuitive syntax:

Short Long Description Example
-h --help Show help message -h
-c --config Configuration file path or URL -c scraper.xml
-w --workdir Working directory -w /tmp
-d --debug Enable debug mode -d
--loglevel Set log level --loglevel DEBUG
--proxyhost Proxy server host --proxyhost proxy.com
--proxyport Proxy server port --proxyport 8080

Legacy Format (Backward Compatible)

The old option=value format is still supported:

java -jar webharvest-cli.jar config=scraper.xml workdir=/tmp debug=true

⚠️ Note: Don't mix modern and legacy formats in the same invocation. Use one format consistently.

⚡ Settings Override Priority

Settings are applied in this order (later overrides earlier):

  1. Defaults - Hard-coded fallback values (lowest priority)
  2. Settings File - webharvest.properties
  3. CLI Arguments - Command-line options (highest priority)

Example

Settings file:

workdir=/default/path debug=false proxyhost=proxy.company.com

Command:

java -jar webharvest-cli.jar -c scraper.xml -w /tmp -d

Final configuration:

  • workdir = /tmp (overridden by CLI)
  • debug = true (overridden by CLI)
  • proxyhost = proxy.company.com (from file)

📚 Usage Examples

Example 1: Basic Usage

# Use settings from ~/.webharvest/webharvest.properties java -jar webharvest-cli.jar -c scraper.xml

Example 2: Override Work Directory

# Override workdir from settings file java -jar webharvest-cli.jar -c scraper.xml -w /custom/output

Example 3: Debug Mode

# Enable debug mode and set log level java -jar webharvest-cli.jar -c scraper.xml -d --loglevel DEBUG

Example 4: Proxy Configuration

# Override proxy settings java -jar webharvest-cli.jar -c scraper.xml \ --proxyhost proxy.example.com \ --proxyport 8080 \ --proxyuser john.doe \ --proxypassword secret123

Example 5: Custom Settings File

# Use specific settings file java -Dwebharvest.settings=/path/to/custom.properties \ -jar webharvest-cli.jar -c scraper.xml

Example 6: Legacy Format

# Backward compatible with old syntax java -jar webharvest-cli.jar \ config=scraper.xml \ workdir=/tmp \ debug=true \ loglevel=INFO

👨‍💻 Developer API

Loading Settings

// Load from default locations
WebHarvestSettings settings = WebHarvestSettings.loadDefault();

// Load from specific file
WebHarvestSettings settings = WebHarvestSettings.loadFromFile(new File("/path/to/settings.properties"));

// Create from Properties object
Properties props = new Properties();
props.setProperty("workdir", "/tmp");
props.setProperty("debug", "true");
WebHarvestSettings settings = new WebHarvestSettings(props);

Building Custom Settings

// Load base settings
WebHarvestSettings baseSettings = WebHarvestSettings.loadDefault();

// Override specific properties
WebHarvestSettings customSettings = new WebHarvestSettings.Builder(baseSettings)
    .workDir("/custom/path")
    .debug(true)
    .logLevel("DEBUG")
    .proxyHost("proxy.example.com")
    .proxyPort(8080)
    .build();

Parsing CLI Arguments

// Parse arguments with base settings
CommandLineParser parser = new CommandLineParser(baseSettings);
WebHarvestSettings finalSettings = parser.parse(args);

// Get parsed configuration file
String configFile = parser.getConfigFile();

// Check if help was requested
if (parser.isHelpRequested()) {
    parser.printHelp();
    System.exit(0);
}
