Command-Line Interface

Unified configuration system

WebHarvest 2.2.0 introduces a unified settings system that works for both CLI and GUI, eliminating the need for separate configuration files.

What's New in v2.2.0

Bug #39 fix - unified configuration

Problem Solved: Previously, WebHarvest required maintaining separate configurations for GUI (webharvest.properties) and CLI (command-line arguments). This caused synchronization issues and confusion.

Now: Single unified configuration system. All settings work in both CLI and GUI.

Command-Line Options

Available arguments for webharvest-cli

Terminal 
# Basic usage
java -jar webharvest-cli-2.2.0.jar config.xml

# With HTTP proxy
java -jar webharvest-cli-2.2.0.jar config.xml \
  --proxy-host=proxy.example.com \
  --proxy-port=8080

# With authentication
java -jar webharvest-cli-2.2.0.jar config.xml \
  --proxy-user=username \
  --proxy-password=password

# Custom user agent
java -jar webharvest-cli-2.2.0.jar config.xml \
  --user-agent="MyBot/1.0"

# Output directory
java -jar webharvest-cli-2.2.0.jar config.xml \
  --output-dir=/path/to/output
