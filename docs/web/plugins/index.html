What is WebHarvest Core?

webharvest-core is the foundation framework that includes everything needed for web scraping:

  • 47 Built-in Plugins - HTTP, XPath, XQuery, Control Flow, Variables, Scripting, File I/O
  • Runtime Engine - Configuration parser, execution engine, context management
  • Plugin System - Auto-discovery, dependency injection, XSD generation
  • Session Management - UUID tracking, metrics, token usage (v2.2)
  • Event System - Guava EventBus integration for lifecycle events

No external dependencies required - all plugins below are included in webharvest-core.
