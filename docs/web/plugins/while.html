<while>

While loop processor

CRITICAL v2.2.0

Overview

The processor executes its body content repeatedly as long as the specified condition evaluates to true. Unlike , which iterates over a collection, continues until a condition becomes false or maxloops limit is reached.

Important Notes

  • Condition evaluation:: Re-evaluated before each iteration
  • Index variable:: Auto-incremented, starts at 0
  • maxloops default:: 100 iterations (safety measure)
  • Infinite loops:: Set maxloops=-1 to disable limit (risky!)
  • test vs condition:: Both attributes work (condition preferred)
